# Checklist do Google Search Console

- [ ] Adicionar a propriedade do domínio `jardelsousadev.com.br`.
- [ ] Validar o domínio por DNS, sem inventar token de verificação.
- [ ] Confirmar `https://www.jardelsousadev.com.br` como versão canônica.
- [ ] Enviar `https://www.jardelsousadev.com.br/sitemap.xml`.
- [ ] Inspecionar a home e solicitar indexação após a publicação.
- [ ] Verificar páginas indexadas, excluídas e motivos de exclusão.
- [ ] Revisar canonical declarado versus canonical escolhido pelo Google.
- [ ] Acompanhar Core Web Vitals em mobile e desktop.
- [ ] Conferir HTTPS e possíveis URLs HTTP ainda descobertas.
- [ ] Revisar usabilidade mobile.
- [ ] Validar dados estruturados e resultados avançados.
- [ ] Acompanhar links internos, backlinks e domínios de referência.
- [ ] Analisar consultas, páginas, países, dispositivos, cliques e impressões.
- [ ] Reavaliar após mudanças relevantes de conteúdo ou estrutura.
